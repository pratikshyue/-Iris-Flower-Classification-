# -Iris-Flower-Classification-

This project is a beginner-friendly Machine Learning project where I worked with the Iris flower dataset to predict the species of an Iris flower based on its measurements.

The dataset contains three species of Iris flowers — Setosa, Versicolor, and Virginica. Using measurements such as sepal length, sepal width, petal length, and petal width, I trained a classification model to identify which species a flower belongs to.

The main goal of this project was to understand how a basic classification problem works in Machine Learning, from preparing the data to training and evaluating a model.

Through this project, I focused on understanding:

How a classification problem works
How to work with a Machine Learning dataset
How to split data into training and testing sets
How to train a classification model using Scikit-learn
How to make predictions using the trained model
How to check whether the model is performing well


The Iris dataset contains 150 flower samples belonging to three species:

   Iris Setosa
   Iris Versicolor
   Iris Virginica

The model uses four measurements:

Sepal Length
Sepal Width
Petal Length
Petal Width

The dataset is available through Scikit-learn and is commonly used for learning and practicing basic classification techniques.

The project follows a simple Machine Learning workflow:

Loaded and explored the Iris dataset.
Checked the different features and target classes.
Visualized the data to understand the relationships between measurements.
Split the dataset into training and testing data.
Trained a classification model using Scikit-learn.
Used the model to predict Iris species from the test data.
Evaluated the predictions using accuracy and other performance metrics.
Reviewed the results to understand how well the model performed.

To check the performance of the model, I used:

Accuracy Score
Confusion Matrix
Classification Report

The final results and visualizations can be found in the Jupyter Notebook included in this repository.
